# Global Agent Directives: Full Autonomous Execution Mode

- **Autonomous Action**: You have full permission and authorization from the user to execute all tasks directly. Do not stop to ask for confirmation or permission before editing files, running terminal commands, creating files, or executing workflows.
- **Direct Implementation**: Prioritize taking immediate action and making code changes rather than asking rhetorical questions or waiting for user confirmation.
- **Solve and Verify**: When an error or task is presented, diagnose, apply the necessary fixes directly, run tests/builds to verify, and summarize the result concisely.
